# 兼容性与降级

| 能力 | 接口 | 失效时行为 |
|---|---|---|
| 首页元数据 | 本机 Codex SQLite，只读 | 显示连接/读取问题，不修改数据库 |
| 实时状态和步骤 | 桌面任务流 v11 | 断线清除实时状态；不支持的版本显示“协议不兼容” |
| 语音提交 | 桌面 owner 发现，start v2 / steer v1 | 提交前核对 owner、任务 id、v11 快照；不兼容不发送，确认不明不自动重发 |
| 账户额度/Token | 官方 app-server 两个只读接口 | 独立结果，失败/缺失/过期明确显示，无登录时不引导隐式登录 |
| 跨应用 Touch Bar | 私有 AppKit/DFR，运行时检测 | 菜单栏诊断可见性；不支持时使用普通菜单栏详情 |
| 语音 | Apple Speech / AVAudioEngine | 优先本机、必要时明确使用 Apple 联网识别；错误不清除已有识别文字 |

工具主要面向 2019 Intel 16 英寸 Touch Bar Mac。旧版曾实测 Finder/TextEdit 切换和重新呈现；每次发布仍应按验收步骤复核。没有实体 Touch Bar 的 CI 不能证明硬件兼容。

“连接成功”只表示路由连接建立，不能证明每个任务协议可用。协议检测按实际收到的任务流逐个判断，不将未经读取的任务猜测为已兼容；每次发送还会重新检查。新版本适配应增加协议夹具并更新本表，不能删除版本检查来强行接入。

系统安全界面可能优先控制 Touch Bar，不承诺任何界面下绝对覆盖。用户手动收起后不会自动抢回。系统睡眠和显示器息屏分别记录和暂停，唤醒恢复同一详情页面。

诊断菜单提供 Codex 版本、任务流状态、额度同步状态、权限状态、可见性和恢复次数。诊断数据不能证明消息最终已经进入 Codex 历史，真实发送仍需在目标任务核对。
